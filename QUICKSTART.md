# Quick Start Guide

## 🚀 Easy Installation

### For Most Users:

1. **Download** the DMG from [Releases](https://github.com/adarsh3699/Bhemu-UNI-Downloader/releases)
2. **Drag** the app to Applications
3. **Launch** the app
4. On first launch, you'll see a setup screen
5. **Click "Start Setup"** - it will install everything automatically (3-5 minutes)
6. **Done!** Downloads will be instant forever

---

## ⚠️ If Auto-Install Doesn't Work

If the automatic setup fails, manually install dependencies:

```bash
# Open Terminal and run:
brew install yt-dlp ffmpeg
```

Don't have Homebrew? Install it first:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Then restart the app - it will auto-detect the installed tools!

## ⚡ Your First Download

2. **Choose** quality (1080p, 720p, audio-only, etc.)

## 🆘 Troubleshooting

### "Installation completed but couldn't verify"

This means the automatic installer had an issue. Fix it manually:

```bash
# In Terminal:
brew install yt-dlp ffmpeg
```

### Downloads are slow to start (10+ seconds)

This means yt-dlp isn't installed correctly. Install manually:

```bash
brew install yt-dlp
```

Then restart the app.

### "Dependencies Missing" error

The app couldn't find yt-dlp. Install manually:

```bash
brew install yt-dlp ffmpeg
```
